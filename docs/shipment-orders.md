# 出貨單

側邊欄「會計 → 出貨單」提供新增、修改、複製、儲存、取消、首筆／上一筆／下一筆／尾筆與查詢。

- 品項包含貨品編號、品名、數量、單位、單價、計算金額、訂單編號與附註說明；不提供依據單號。
- 下方分頁提供交易備註、发票資料、帳款日期／付款條件與建立／更新時間。
- 發票資料包含課稅類別、日期、編號、開立方式、聯式與金額。尚未開票可留空，零元與未填金額分開保存。
- 客戶沿用目前客戶名單；單據保存當時客戶名稱與指送資料，不因客戶改名而改寫歷史。
- 單號方式可選「依日期生成」或「自行輸入」。自動編號採 `YYMMDD` 加四位每日流水號，例如 `2610070001`；儲存時以交易分配，包含既有手動號及作廢號，避免重複。每天最多 9999 號。手動編號保留前導零，修改日期會重新分配自動號。
- 金額使用 Decimal：數量、單價最多三位小數，每列捨入到整元後加總；整元捨入採 ROUND_HALF_UP。外加、內含、免稅、零稅率分別保存，稅率預設 5%，可以修改。此為新模組規則，未改动任何既有配方、生產或庫存計算。
- 第一版採一張出貨單對一張發票，非空發票編號不可重複；記錄發票資料不代表已向平台開立。合併／拆分開票與電子發票串接為後續功能。
- 發票金額獨立保存，不自動以出貨總額覆寫。
- 單據為草稿，保存不會扣庫存、產生傳票或收款。帳款分頁先提供基本欄位，未宣稱已建立應收帳款。
- 编辑中停用單據切換、搜尋與其他側邊欄頁面；取消恢復已保存資料。修改採 version 檢查，拒絕舊版本覆蓋。
- 工具列合併為單一橫排，指送對象編號、名稱與地址同排；下方分頁採緊湊欄位，品項區固定高度捲動。
- 作廢需要原因與勾選確認，保留品項和發票歷史。「列印預覽」保留首筆／上一筆／下一筆／尾筆切換，可連續查看不同出貨單。
- 列印採 A5 橫式，抬頭為佳味實業有限公司、台南市永康區中正南路309號、電話 06-2536526、傳真 06-2537869。長品項或備註自動分頁。可在預覽按列印，或下載 HTML 後使用瀏覽器列印。
- 勾選「隱藏單價與金額」時，預覽與下載檔均不包含單價、品項金額、合計、稅額與總計，不只是將欄位以 CSS 隱藏。

## 資料與升級

Schema v23 加入 shipment_orders、shipment_order_items、shipment_invoices；v24 加入 shipment_number_sequences 保存每日流水號。表頭、明細、發票以既有 connect_from_config 的交易一起保存。正式資料沿用 SQLite／Turso，不直接寫入 Google Sheets，也未新增未實作的 Sheet 同步事件。

首次部署由既有 schema 初始化建立新增資料表，不修改既有資料表及其業務計算。請先在測試 branch／測試 Streamlit app 與獨立 Turso database 驗收，再合併正式版本。

程式分為 utils/shipment_repository.py（計算、驗證、持久化）、utils/shipment_print.py（列印格式）及 utils/shipment_ui.py（Streamlit 畫面）。日後 FastAPI 可直接使用 repository 與列印功能，前端再改為 React／Vue。

## 測試

```bash
python -m pytest tests/test_shipment_repository.py tests/test_shipment_ui.py -q
```

測試只使用暫存 SQLite，涵蓋計算、客戶快照、發票資料、衝突回滾、舊版本拒絕、schema 升級、作廢、列印轉義，以及 Streamlit 單據切換、儲存與取消。
