# 更新既有出貨單的客戶資料

客戶主檔改名不會直接改寫已保存的出貨單。需要修正原單時：

1. 開啟原出貨單並按「修改」。
2. 展開客戶欄下方「更新客戶資料」，按「讀取最新客戶資料」。
3. 查看目前單據與主檔的差異，選擇要更新的欄位。
4. 按「套用選取欄位」，確認畫面後再按出貨單的「儲存」。

預設只選取有差異的名稱欄位。地址、電話、傳真、聯絡人與統一編號須自行選取，
可選擇以主檔空白值清除舊值。若另有指送對象，指送名稱及聯絡／送貨資料來自該對象；
客戶名稱仍來自開單客戶。未填指送編號時，不推定或更新指送名稱。

讀取會直接查主檔，不使用出貨單既有的客戶清單快照；普通欄位修改不會因此重讀。
換客戶、指送編號或開始另一份草稿後，先前的更新預覽失效，需重新讀取。
讀取失敗會清除舊預覽並保留草稿，避免套用先前讀取的資料。

套用只改目前草稿；取消會放棄更新。保存沿用原單 ID、單號、版本與既有交易，
不另建單據。此操作不會修改品項、單價、發票或收款紀錄。

測試：`tests/test_shipment_customer_refresh.py` 驗證選擇性套用、另行指送、
空白值、取消、讀取失敗、預覽失效，以及保留原單號、草稿品項／備註與收款。
