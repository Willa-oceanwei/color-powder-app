# 待載回清單的資料更新

「待載回代工單」仍只列出狀態為未載回／進行中，且累計載回量低於目標的單據。
相同配方的已結案歷史單據不因配方相同而重新列入。

原本代工頁的整份 session 快照可一直沿用，切到別頁再回來也不更新。
現在重新進入代工管理時，會重載主檔與送達／載回紀錄；同頁普通輸入繼續重用快照。
載回分頁內也提供「重讀待載回清單」，可直接取得其他工作階段已結案的最新結果。

待載回篩選與數量卡片統一使用標準化單號的載回紀錄索引，
避免舊紀錄單號的大小寫或空白差異使卡片顯示 0。數量字串的千分位逗號也會正確解析。
歷史紀錄仍保留在「更正載回紀錄」與「代工歷程查詢」，不更改主檔狀態或刪除資料。

測試使用同一配方 `68023CM` 的已結案、已足量載回但狀態未更新、部分載回與尚在廠內單據，
驗證選單只保留部分載回單；另一工作階段結案後，重讀會將它移出選單。

這次修正可重現的快照更新及數量比對問題，未直接讀取或修改正式資料庫，
因此不據此判定截圖中每一張單據的實際結案狀態。
