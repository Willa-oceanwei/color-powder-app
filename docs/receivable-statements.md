# 應收帳款明細表與選填收款

入口：左側「明細 → 應收帳款明細表」。以客戶編號區間和帳款日期區間查詢；不是出貨日期區間。
預覽按客戶排序，每位客戶獨立分頁，多頁客戶連續顯示。可切換首／上／下／末頁，下載 HTML 或列印整批 A4 橫向報表。
報表使用已儲存且未作廢出貨單；品項與稅額為出貨單快照。不同單位的數量分開合計，不將包與 KG 相加。

「收款登錄」可選客戶、出貨單、日期、整數元金額、方式、憑據及備註。完全選填，不影響新增出貨單。
可分次收款，同一出貨單有效收款不可超過出貨總額；本版尚不支援一筆跨多張出貨單或未分配的預收款。

出貨單頁上方查詢也可輸入起始／結束客戶編號及出貨日期區間，任一端可留空。兩種條件同時提供時取交集。
查詢結果列表可點選單列開啟出貨單，再用上一筆／下一筆切換。日期及客戶編號區間包含起訖值。
畫面不顯示訂單編號；歷史訂單編號保留於資料庫，編輯其他欄位不會抹除它。
收款不可直接刪除或修改，誤登時作廢並重新登錄，保留原紀錄及作廢原因。
已有有效收款的出貨單不可變更客戶、減額至已收款以下或直接作廢。先作廢相關收款後才能操作。
收款寫入與作廢會更新出貨單版本，防止同時編輯覆蓋。

報表「截至期末已登錄收款」只計入所選出貨單、收款日期不晚於查詢結束日的有效收款。
「帳面未收餘額」是本期出貨總額減上述收款，不代表未登錄的實際付款不存在。
這是本期出貨明細，不含期初餘額、過往期間出貨、退貨、折讓及未分配預收款；不是完整客戶往來總帳。
登錄或作廢收款後會清除本工作階段的舊預覽；重新按預覽即可取得最新報表。
其他使用者登錄收款或修改出貨單後，也需按預覽重新查詢。

資料分三層：Streamlit 介面、報表／收款服務、SQLite/Turso 資料庫。報表查詢與 HTML 列印不依賴 Streamlit，方便未來接 FastAPI。
