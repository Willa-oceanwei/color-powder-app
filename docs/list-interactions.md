# 清單選取與分頁

生產單記錄表、預覽／修改查詢以及出貨單查詢結果使用清單左側的資料列選取欄。
多筆結果尚未選取時只顯示操作提示，選取後出現單號與該筆可用操作。
僅一筆結果會自動帶入。生產單列印仍下載原有 A5 HTML，開啟後啟動列印視窗；
製作標籤沿用既有編輯器、校正與儲存流程。

出貨單查詢列印直接使用選取單據，不再顯示第二個出貨單選擇下拉。
編輯中不允許從結果切換單據；既有暫存草稿及繼續草稿流程不變。

共用 `utils/list_ui.py` 的選取表格只回傳原始資料，顯示簡稱不會改寫完整名稱。
表格識別包含目前可見單據的有序 ID；翻頁、篩選或重排可見單據後，舊選取不會
落到另一筆資料。原始記錄與顯示資料列必須同序且等長。

共用分頁列保留筆數摘要、上一頁、目前頁碼與下一頁；「⋯」內提供每頁筆數與跳頁。
頁數邊界的按鈕停用，跳頁使用 callback 即時更新頁面，變更每頁筆數回第一頁。
生產單記錄表新工作階段預設每頁 20 筆；既有工作階段保留原偏好。
手機寬度保留同列的分頁按鈕，總筆數可在分頁設定查看。

本階段套用生產單兩個查詢工作區及出貨單查詢；共用分頁列的既有呼叫頁面
（配方、生產單及試色分析）一併採用精簡分頁。其他獨立編寫的清單尚未全面替換。
本次不修改資料庫 schema、金額、庫存或單據計算。
