# 客戶簡稱與完整名稱

「設定 → 客戶名單」可分別維護「客戶完整名稱」及選填的「客戶簡稱」。
內部清單、客戶選單、出貨查詢、收款登錄及每月收款總覽優先顯示簡稱；
未填簡稱時沿用完整名稱，未建檔的歷史名稱保留原文字。
完整名稱仍可在客戶編輯表單中維護，也能用於客戶名單及收款總覽搜尋。

資料庫 schema 31 自動新增 `customers.short_name`，既有 `name` 保留為完整名稱，
不推測或截斷公司名稱。修改簡稱保留舊名稱別名，以對應僅存名稱的歷史紀錄。
同一簡稱或別名不可分配給其他客戶，避免名稱對應歧義。
內部呈現只格式化標籤及表格副本，不改動選項值、歷史資料、數量或金額。

出貨單使用完整名稱快照；應收帳款明細表、客戶交易明細表與其 PDF／Excel
繼續使用完整名稱。修改簡稱不會改寫已儲存的出貨單。

Google Sheet「客戶名單」同時有「客戶名稱」及「客戶簡稱」標題時，outbox
會分別同步完整名稱與簡稱。舊 Sheet 僅有「客戶簡稱」一欄時，仍在該欄保留
原本的完整名稱，並回報同步警告，避免完整名稱遺失；若需要在 Sheet 同時維護
兩者，請新增「客戶名稱」欄，保留原有欄位。之後編輯儲存客戶即可同步兩者。
舊事件 payload 也按單一完整名稱處理。匯入省略簡稱欄時保留已存簡稱；
新格式明確將簡稱欄留空時會清空簡稱，內部顯示改用完整名稱。

每月收款總覽改為有邊框的篩選區、三張金額摘要卡及客戶收款清單。
窄螢幕會將卡片垂直排列；搜尋支援編號、簡稱及完整名稱。
搜尋或「只顯示未收」只篩選清單，上方金額仍為全部客戶合計，畫面有明確註記。
帳款期間、結帳日、收款截至日、金額公式及收款沖帳規則均沿用原邏輯。
