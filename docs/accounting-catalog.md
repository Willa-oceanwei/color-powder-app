# 會計貨品與配方連動

- 會計側欄包含出貨單、應收帳款、各式明細（客戶交易明細／客戶交易排行）、設定選項（貨品資料）。
- 貨品資料的「查詢／配方定價」可搜尋並選取現有配方，按「補上定價」建立貨品或修改已建立貨品。
- 建立貨品時，配方編號帶入貨品編號、顏色帶入品名、計量單位帶入規格。KG、g、包、桶等單位可直接帶入基本／銷售單位；例如 1000g 這類包裝描述只帶入規格，銷售單位仍可設定。
- 出貨單「加入貨品／配方」及明細表直接輸入已知編號皆可帶入品名、單位與售價。僅對新編號或變更編號套用預設，不覆蓋同編號手動修改的資料。
- 品項附註說明預設空白，不自動帶入貨品規格；可自行填寫且非必填。既有出貨單的附註保留。
- 表格直接輸入完整配方編號可查找所有有效配方，不限配方原屬客戶；候選選單仍優先列出目前客戶配方。單價依目前出貨客戶查找，不帶入其他客戶成交價。
- 帶價優先採同客戶、同編號、同單位、同課稅方式且日期不晚於本單的最近有效出貨；無歷史才採相符單位與課稅方式的貨品標準售價。
- 直接輸入編號後再修改單位，會重新查找該單位的前次成交價；同次修改若另填單價，優先保留手動輸入的單價。
- 已建立的有效貨品可供不同客戶購買，不因原配方的客戶歸屬而隱藏；未建立貨品的配方候選仍限所選客戶或共用配方。停用貨品或停用關聯配方不列入候選。
- 出貨單成交價依客戶記錄於有效出貨歷史，不回寫共用標準售價。「同步建立缺少貨品」只建立不存在的貨品，初始標準售價為 0，避免首位客戶的成交價套用到其他客戶；共用標準售價由貨品資料設定。停用貨品會拒絕同步，出貨單也不會部分儲存。
- 出貨單稅率只提供 0%（免稅）及 5%，與發票課稅類別同步。舊單瀏覽保留原稅率；修改儲存時改用上述選項。單價顯示移除尾端小數零，計算與儲存精度不變。
- 外包裝與售價 C/D/E 不再顯示，但舊值保留，不刪除歷史資料。
- 編輯出貨單／貨品時可切換工作模組，未儲存草稿保留在目前登入階段。重新整理、重新登入或伺服器重啟不保證草稿保留，重要資料仍應先儲存。
- 已儲存出貨單開啟「預覽／列印」，在預覽工具列按「列印」。嵌入預覽受瀏覽器限制時，可下載 A5 列印版 HTML 後在瀏覽器開啟並列印。
- 出貨單抬頭為佳咊實業有限公司，A5 橫式。公司名 18pt、單名 19pt 使用標楷體（優先 DFKai-SB），內文 12pt 維持黑體（優先 Microsoft JhengHei）。未安裝指定字型時使用後備字型。明細固定欄寬、金額千分位、數字靠右；最多 7 行明細與每頁 3 行備註，較長內容分頁，保留底部簽收區。
- 出貨單品名自動帶入後可直接在表格修改，手動名稱隨該筆出貨單儲存與列印，不回寫配方或貨品名称。
- 品項表格提供「採購單號」，可逐品項輸入客戶的採購單號，對應列印欄位；沿用原明細 order_number 資料，不刪除舊值。
- 草稿欄位只從 Session State 初始化一次，widget 的 value 保持 None、選單 index 固定為 0，避免保留草稿或自動帶入時產生重複預設值警告，並保持元件身分穩定。必填日期清空時提示補填，不自動改回今天。
- 發票聯式提供三聯式／收銀機，開立方式提供隨單開立／月結開立。新單預設三聯式、隨單開立；舊單的其他值保留為目前選項，不強制改寫。
- 發票金額依使用者要求自動帶入「稅額」，不是含稅總計。尚未手動修改時隨品項及稅率更新，手動修改後保留原值；已儲存非空金額在修改單據時不自動覆蓋。不改變出貨單的稅額、總計或應收計算。
- 明細表與排行提供 PDF 與 Excel。明細 Excel 分為交易明細、客戶合計兩張表，避免重複加總單據金額；文字儲存為文字而非公式。
- 生產單同步新增出貨單尚未加入，待會計模組確認後再安排。
