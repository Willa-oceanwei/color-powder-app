# 貨品

會計 → 貨品提供查詢、新增、修改、儲存、取消、首筆／上一筆／下一筆／尾筆、刪除及恢復。刪除為停用，需原因與確認，不實體移除，也不修改歷史出貨單。修改採版本檢查，貨品編號建立後不可直接改號。

## 欄位

- 貨品編號、名稱、可選的關聯配方及供應商。新貨品選擇配方時，空白的編號與名稱預填配方編號與顏色；已輸入值不覆寫。
- 類別、規格、基本單位、內包裝單位與容量、外包裝單位與內包裝數量、銷售單位、備註。
- 標準成本、期初成本、現行成本；標準售價、售價 A～E；幣別 TWD 與定價課稅方式。
- 售價按銷售單位保存。包裝資料僅記錄規格，不自動換算售價或扣庫存。三項成本為手動主檔資料，不代表已建立庫存成本核算。A～E 暫供保存，尚未建立客戶價格等級套用規則。

## 出貨帶入

新增或修改出貨單時，展開「加入貨品／配方」。貨品優先於同編號配方；無貨品主檔的既有配方仍可選取。停用貨品不再出現在選單，也不以同編號配方繞過停用。

選取貨品時預填銷售單位。單價優先使用同客戶、同編號、同單位、同課稅方式、出貨日期以前最近一張已儲存且未作廢的出貨單；無相符歷史才使用貨品標準售價。標準售價的單位或課稅方式不符時不套用，顯示提示並先填 0，由使用者確認價格。原始配方且無定價記錄時同樣填 0。

名稱與規格帶入出貨明細名稱及附註，之後可手動修改。主檔名稱、價格更新或停用不回寫歷史單據。直接在明細表填寫自由品項仍須自行填價。

關聯配方屬特定客戶時，只列出該客戶；無關聯配方或配方未指定客戶的貨品可供各客戶選用。此階段尚未建立生產單轉出貨、品項組裝、庫存數量與貨品圖片功能。
