# 客戶編號修改

在「客戶名單」搜尋並選取既有客戶，修改「客戶編號」後按「儲存變更」。
編號以文字保存，保留前導零。空白編號及已存在的編號（含停用客戶）會被拒絕。

儲存時在同一筆資料庫交易中更新客戶別名、配方、試色、出貨單客戶與指送編號、
收款批次及預告報價的客戶關聯；含有客戶編號的舊生產單 payload 也同步更新。
配方成分、數量、單價、金額、稅額、收款分配及歷史配方快照均保留。
任何檢查或寫入失敗會整筆回滾。使用者開啟表單後若客戶版本已改變，須取消後重讀。

改號會提高相關單據版本。其他已開啟的舊出貨單草稿可能收到版本衝突，請先保留需要的
修改內容，再取消並重讀新版本。客戶主檔與相關查詢快取會在儲存後失效。

Google Sheets 沿用現有 outbox 同步流程：新客戶編號排入新增，舊編號排入刪除，
配方、試色及帶編號的生產單排入更新。安全同步若保留刪除事件，需於同步檢查執行
既有 PUSH。舊 Sheet 資料若被別人修改，會列為衝突，不直接刪除；已刪除／改號的舊
編號被重新帶回時也會列為衝突，避免重建舊客戶。新編號仍有 Sheet baseline，
或相關資料正在處理同步時，請完成同步後再改號。

本功能使用既有資料表，不修改資料庫 schema；測試以本機 SQLite 與模擬 Sheet 執行。

改號後，尚未儲存的舊配方、試色或帶客戶編號的生產單若仍送出已移除的編號，
會提示重新讀取；Sheet 匯入也會拒絕該舊關聯。新出貨單的指送編號同樣檢查，
避免重新建立已被改號移除的關聯。
