# 客戶聯絡資訊與出貨帶入

「設定 → 客戶名單」新增五個選填文字欄位：地址、電話、傳真、聯絡人、統一編號。
電話、傳真及統編不作數值轉換，保留前導零。既有客戶升級後欄位預設空白，需編輯補上。

新增或編輯出貨單，選擇不同客戶時，會帶入送貨地址、聯絡電話、傳真號碼、聯絡人及統一編號。
這些都是該張出貨單的快照，能再修改；更換成沒有資料的客戶時會清空，避免沿用前一位客戶資訊。
儲存後修改客戶主檔不會更新舊單。開啟舊單編輯也不會覆蓋已存地址；只有換客戶才重新帶入。
複製出貨單沿用原單快照，同樣可再修改。列印及帳款明細表使用出貨單快照。

Turso 是主檔正式來源。Sheet outbox payload 包含新增欄位，Sheet 副本依既有欄位同步；沒有相同標題的欄位不會寫入。
舊格式 Sheet 匯入時缺少新增欄位，會保留主檔既有聯絡資訊；有欄位但明確空白，才清空該欄位。
舊版程式只傳編號、名稱及備註更新客戶時，也不會清空新欄位。
